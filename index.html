About

There's so much good public data. I want it to be easy to see.

I work in international development, and every day I see how much useful data is published, and how hard it can be to read. So in my own time I build dashboards that make it clear in a minute.

Each week I pick one topic that matters to people working in development and humanitarian programmes, pull the latest public figures, and turn them into a dashboard anyone can explore.
